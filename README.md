# cityWalk-game

cityWalk 抽取任务小游戏：出门散步前抽一张任务卡，按卡面提示完成一件小事。

主要形态是微信小程序「四季散步任务卡」，同时保留了一份可离线打开的单文件 H5 版本。

## 功能

- **抽卡**：一次抽 1–5 张，洗牌动画后翻牌揭示任务
- **不重复抽取**：抽过的卡本轮不再出现，抽完自动重新洗牌，可随时关闭
- **卡池**：单条添加、批量导入（每行一条，`小标题|任务内容`）、恢复默认、清空
- **记录**：自动记录每次抽卡，点击可标记完成，未完成的任务会锁住下一次抽卡
- **四季主题**：春 / 夏 / 秋 / 冬背景，默认按当前月份自动选择，可手动切换
- **数据保存**：本地缓存优先，云端异步同步兜底，断网照常可用

## 本地运行（小程序）

1. 用微信开发者工具导入 `miniprogram/` 目录
2. `miniprogram/app.js` 顶部的 `CLOUD_ENV` 改为自己的云开发环境 ID
3. 云开发控制台新建集合 `citywalk_states`，权限设为「仅创建者可读写」
4. 编译即可；云端不可用时会自动降级为纯本地模式，仅提示一次

> `project.config.json` 中的 `appid` 如需替换，改成自己的小程序 AppID。

## 本地运行（H5）

直接双击打开 `game-cityWalk.html` 即可，无需服务器和构建步骤，数据保存在浏览器 `localStorage`（键名同为 `citywalk.draw.v1`）。

H5 版完成一张任务后会弹出通关页，文案取自 [app.js](app.js) 顶部的 `PROMO_TEXT`，用于引导到小程序，可按需修改。

`xhs-minitool/index.html` 是内容相同的副本，用于在小红书等平台发布小工具。

## 数据说明

| 项目 | 说明 |
| --- | --- |
| 本地存储键 | `citywalk.draw.v1` |
| 云端集合 | `citywalk_states`，每个 `openid` 一条 |
| 同步策略 | 本地优先：启动后按 `updatedAt` 对比，云端新则采用，本地新则上传；写入 800ms 防抖、切后台立即冲刷、串行写入 |
| 上限 | 卡池 300 张、记录 200 条、单次导入 100 条 |
| 默认任务 | 15 条内置散步任务，删除后可「恢复默认」找回 |
